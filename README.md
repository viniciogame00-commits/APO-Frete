#Gerenciador de fretes

Este é um aplicativo basico para gerenciamento de fretes no qual é possível adicionar os produtos que seram transportados, os transportadores (empresas ou freelancers), os endereços de entrega e que no fim entrega um relatório dos fretes do dia

Este aplicativo utiliza das tecnologias PHP, HTML, CSS, JavaScript, Bootstrap e MySQL
